## Design

Bloxwap Sans is a neo-grotesk with every terminal rounded. Curves are smooth and nearly circular, bowls close cleanly into their stems, apertures are open (the ends of `c`, `e`, `s` and `a` stop well short of closing), and the x-height is tall: 540 units against a 720-unit cap height, on a 1000-unit em. Capital `I` has rounded horizontal bars to distinguish it from lowercase `l` by default. For essential text, start around 16 px in Regular or Medium and check readability at the actual size, contrast and weight. See [Accessibility](/docs/usage#accessibility) for testing guidance.

It is built for numbers that move. Figures are **tabular by default**: every digit has the same width, so prices, balances and table columns stay aligned while they update. Proportional figures are one feature away for running text.

| Metric | Value |
| --- | --- |
| Units per em | 1000 |
| x-height | 540 |
| Cap height | 720 |
| Ascender / descender | 760 / −210 |
| Regular stem | 84 |

## Weights and italics

<AxesTable id="sans" />

Italics are true italics: the skeletons are slanted 9° before stroking, so italic strokes keep the same weight as upright ones.

## Stylistic sets and features

Stylistic sets swap in alternates without changing the text: a single-storey `a` (`ss01`), open `4 6 9` (`ss02`), a `y` with a curved tail (`ss04`), simplified `G Q R` (`ss05`), a flat-top `3` and plain `1` (`ss06`), and a curved foot on `l` (`ss08`, which also retains the barred `I` alternate). Bloxwap Sans also has small capitals, case-sensitive punctuation, fractions, superiors and inferiors, ordinals, slashed zero, arrow ligatures (`dlig`) and localized forms for Romanian, Catalan, Serbian, Macedonian and Bulgarian. See the full table with live previews in [OpenType features](/docs/opentype-features).

## CSS

```css
body {
  font-family: "Bloxwap Sans", ui-rounded, system-ui, sans-serif;
  font-weight: 400;
}
.prose { font-variant-numeric: proportional-nums; }
.price { font-variant-numeric: tabular-nums slashed-zero; font-weight: 560; }
```

Set up the files with [Installation](/docs/installation).
