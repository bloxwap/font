## How it is measured

Language support is computed from the shipped font files with [Hyperglot](https://hyperglot.rosettatype.com), Rosetta's database of orthographies. A language counts only when the font has **every** character of its base orthography, including marks that must combine correctly. The lists below are regenerated on every build, so they always match the fonts.

Hyperglot's counts work well for alphabets. For Korean, Chinese and Japanese, a language needs thousands of characters, and partial sets (a font in development, or a font with the 3,500 most common hanzi rather than every ideograph) may not count as complete. For those scripts, the character coverage below says more.
