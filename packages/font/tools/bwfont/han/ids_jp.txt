# ids_jp.txt — Japanese (Jōyō, shinjitai) decompositions: the 'jp' layer.
# Overrides shared ids_a/ids_b data for the JP families only.  Format: char<TAB>IDS.
# Full-form radicals are written as themselves (言 糸 金 飠 門 貝 見 車 馬 魚 鳥 頁 長 韋 東);
# the engine picks their positional forms (言.L, 貝.L, 頁.R …).
# Never decompose a character here that is drawn as a component (門 貝 戸 円 …): the jp
# layer wins over COMPONENTS and would bypass the drawing and its positional forms.
#
# NEW ATOMS / TOKENS (designer to-do list; generated, see bottom of header)
# Every count follows Unihan kTotalStrokes (PRC convention: 辶=3, 阝=2, 艹=3).
# Full-form radicals already drawn in components_jp.py are not listed (言 糸 金 飠 門 貝 見
# 車 馬 魚 鳥 頁 長 韋 東 戸 円 両 為 亀 歯).  ×N = number of Jōyō kanji using it.
#
